v0.1.0（2026-11-03）
================================================================================

首个正式发布版。以 TVBox 风桌面客户端为核心，内置百度网盘直连播放。

【新增】百度网盘直连播放（平台内置，无需 AList）
  · OAuth 授权：设置页「网盘」一键打开授权页，粘贴授权码即完成绑定
  · 目录浏览：面包屑导航浏览网盘目录，视频文件直接播放并自动计时
  · 目录一键生成课程：递归扫描当前目录，按自然序生成课程章节
    （「第2讲」不会被排到「第10讲」之后），生成后直接进入课程详情
  · 服务端流代理：自动携带百度要求的 User-Agent 与 Range，
    支持拖动进度条、跳到文件尾部；直链按 10 分钟缓存
  · 令牌只保存在本机服务端（.utopia-data，不入仓库）；
    续期单飞 + 轮换回写，避免并发刷新互相作废
  · 三个实测踩坑已修复并在单测中锁定：
    - 百度 CDN 只认「直链 + access_token」，仅带 UA 会 403 user not exists
    - filemetas 接口的条目字段是 list 而非文档中的 info
    - refresh_token 每次续期轮换，旧令牌立即作废

【新增】TVBox 配置地址驱动
  · 设置页填一份 TVBox 接口 JSON 即可导入点播源、解析线路与壁纸
  · 分类浏览页（/browse）：按站点分类翻页浏览
  · 解析线路面板：播放页一键切换解析
  · 多仓库配置（urls:[...]）自动跟随；依赖 Spider 引擎的站点跳过并说明原因

【新增】壁纸系统
  · 三种来源可切换：跟随 TVBox 配置 / 我的图片（本地导入）/ 关闭
  · 本地图片存 IndexedDB（单张上限 12MB，支持多选导入），
    导入即启用；删除当前壁纸自动回落
  · 压暗程度（0-95）与显示方式（铺满裁切 / 完整留边）可调
  · 壁纸模式统一深色玻璃 HUD 调色板：白字 + 蓝强调色，
    不受系统主题与壁纸明暗影响（黑字压暗图看不清的问题已修复）
  · 卡片 / 输入框 / 顶栏半透明 + backdrop 模糊，关闭壁纸即恢复实色

【新增】按学习进度自动续播
  · 采集站、课程章节、网盘视频统一生效：看到一半离开，
    再进来提示「已从 xx:xx 继续播放」
  · 距结尾不足 15 秒不再续播（避免一进去就结束）
  · 看完自动清进度，下次从头播

【修复】播放器
  · 按地址类型分流 HLS / 原生播放：此前 type 硬编码 'm3u8'，
    mp4 直链（含网盘流）被硬塞给 hls.js 导致永远播不出来；
    换集同样按类型分流
  · 代理只对「等响应头」限时：此前 8 秒整流超时会掐断大文件，
    185MB 视频播到 8 秒必断、播放器反复重连，表现为「加载极慢」；
    现在拿到响应头后无限时长流式透传
  · 客户端断开时终止上游请求，不再留废弃连接占网盘配额

【改进】桌面客户端
  · 移除伴生程序与 mpv：播放全部在内置播放器完成，
    安装包从 160.5 MB 减至 116.8 MB，无需 Python / mpv / companion
  · 移除应用菜单栏：Ctrl+, 打开设置、F11 全屏、Ctrl+=/-/0 缩放
  · 内网上游放行开关（默认开，仅监听 127.0.0.1）；
    Web/Docker 部署用 ALLOW_PRIVATE_UPSTREAM=1 显式开启
  · 渲染层日志转发到 desktop.log，错误页显示技术细节，便于排查
  · 设置窗只保留必要项（B 站登录项随伴生程序一并移除）

【改进】服务端架构
  · 服务核抽出为宿主无关层 src/server：Next.js Route Handler
    与 Electron 主进程共用同一份逻辑（一份代码、两个宿主）
  · SSRF 防护：字面量 + DNS 双重校验、逐跳重定向复检、
    下载域名限定百度系，不做开放代理
  · HLS 清单识别改按 URL 路径（剥查询串）：自建网盘直链
    形如 /p/xxx.m3u8?sign=… 且返回 octet-stream，此前两个判据全落空

【清理】
  · 移除 LibreTV 的 Web 端配置（访问密码、.env、Docker 配置项）
  · 移除旧架构：Capacitor 移动端（app/）、安装包分发服务（backend/）、
    旧移动端截图（screenshots/）；安装包统一由 GitHub Releases 分发
  · 示例复习计划为通用占位内容，不含任何个人数据

【质量】
  · 测试 618 例 / 46 个文件全部通过；typecheck / lint 零错误
  · 发布前对源码与安装包产物做个人数据全文扫描（零命中）
