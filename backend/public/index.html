    Android 安装说明

    1. 点击上方「下载安装」，等待 APK 下载完成
    2. 打开通知栏的安装包，或在「文件管理 → 下载」中找到它
    3. 首次安装会提示「禁止安装未知来源应用」，前往 设置 → 安全 → 开启「允许安装未知应用」
    4. 回到安装界面，点击「仍要安装」即可完成

    小米 / 华为 / OPPO / vivo / 荣耀等品牌提示路径略有不同，本质都是开启「允许未知来源」。
