## 一、项目概述

### 1.1 项目背景（原文保留）

面向考研备考人群，实现可自定义目标考试日期的倒计时、学习计时打卡、记录每日学习科目与学习内容、各学科时间占比饼图统计、累计/日均时长统计。整体为单机本地应用，无后端服务器，所有数据保存在设备本地，不需要登录注册。

### 1.2 产品目标（原文保留）

1. 倒计时组件：用户可自由设置目标考试日期，自动计算剩余天数，不写死固定日期
2. 学习计时：开启计时，选择学习科目，结束计时保存记录；每条记录填写本次学习的具体内容
3. 统计模块：支持日/周/月维度，展示学科时长、饼图占比、累计专注时长、日均专注时长
4. 历史日志：查看全部历史学习记录，支持编辑、删除旧记录
5. 完全本地存储，离线可用

### 1.3 运行环境

- 目标平台：Android（主），兼容 iOS
- 开发框架：**Flutter**（新增，见 1.4）
- 存储：本地 SQLite

### 1.4 技术选型（新增）

| 关注点 | 选型 | 说明 |
|---|---|---|
| 框架 | Flutter 3.x | 单代码库出 Android/iOS |
| 状态管理 | Riverpod（或 Provider） | 推荐 Riverpod：可空状态好、可测试；简单场景 Provider 足够 |
| 本地数据库 | `sqflite` + `path` | 满足两表需求；数据量大后可平滑迁移到 `drift` |

| 倒计时过期处理（新增） | 剩余天数 ≤ 0 时，卡片文案切换为"已到考试日期"，副文案显示"考试已结束 X 天"，庆祝色块 |

#### 模块2：学习计时（核心，原文 + 增强）

1. 科目下拉：数学 / 英语 / 408数据结构 / 408计算机网络 / 408操作系统 / 408计算机组成原理 / 其他
2. 计时器：开始 / 暂停 / 结束；结束弹出保存弹窗
3. 多行输入：本次学习内容
4. 确认保存写入本地数据库

计时规则补充（新增/明确）：
- 计时基于**开始时间戳**计算，界面用 1s 定时器刷新显示，不依赖内存累计（防漂移）。
- 暂停：记录暂停点，暂停期间不计时（见 2.3.4 计时状态机）。
- 时长取整：`duration_min = ceil((end - start) / 60000)`，即 1 分 30 秒记 2 分钟。
- 不足 1 分钟（< 60s）禁止保存，弹提示"学习时长太短，未保存"。
- 跨零点归属：`record_date` 取**计时开始时间戳所在日期**（学到凌晨的时长记在前一天）。

#### 模块3：统计图表（原文 + 口径锁定）

1. 时间筛选器：日 / 周 / 月（口径见第六节）
2. 统计指标卡片：累计专注次数、总学习时长、日均专注时长、当前周期总时长
3. 饼图：各科时长与百分比（fl_chart PieChart，固定科目配色见第九节）
4. 各科耗时列表
5. 空态（新增）：当前周期无记录时显示占位图"本周还没有学习记录，去专注一下吧"

#### 模块4：历史日志（原文 + 增强）

1. 按日期倒序展示全部记录，分页加载，每页 20 条（性能要求）
2. 每条展示：日期、科目、耗时、学习内容
3. 支持编辑、删除单条记录
4. 顶部日期筛选：默认"全部"，可选择指定日期看当日日志
5. 编辑弹窗（新增明确）：可改科目、耗时（分钟）、学习内容、日期，保存后统计页实时刷新
6. 右上角【＋】入口：手动补录（见模块6）

#### 模块6：手动补录（新增）

触发：历史日志页右上角【＋】。场景：忘记开计时。

弹窗字段：日期（默认今天）｜科目（同下拉）｜时长（分钟步进器）｜学习内容（多行）。
保存逻辑：补录不产生真实起止时间戳，按 `日期 + 时长` 反推占位时间戳，`record_date` = 所选日期，`duration_min` = 所选时长。
校验：时长 ≥ 1 分钟且 ≤ 1440 分钟（超过一天视为异常，提示确认）。

#### 模块7：数据备份与恢复（新增）

- 导出：一键生成 JSON 文件（格式见第七节），经系统分享面板存到本地 / 网盘 / 发给自己。
- 导入：从文件选择器读取 JSON，默认**合并模式**（按 `recordId` 去重，新记录追加，重复记录跳过）；提供**覆盖模式**（清空后导入）。
- 导入前做格式校验，失败给出可读错误，不破坏现有数据。

#### 模块8：设置与数据清理（新增）

- 设置项：每日学习时长目标（可选，0 表示关闭）、每日学习提醒（可选，flutter_local_notifications）。
- 清空数据：一键清空全部学习记录（保留考试日期配置），需二次确认输入"清空"。
- 关于：版本号、开源许可。

#### 模块5：倒计时设置弹窗（原文保留）

- 触发：首页倒计时卡片右上角齿轮
- UI：系统日历日期选择器
- 操作：【取消】【确认保存】
- 确认：写入 `app_config.exam_target_date`，首页重算刷新

### 2.3 关键需求澄清与决策（新增，重要）

| # | 决策点 | 结论 |
|---|---|---|
| 2.3.1 | "周"的定义 | **自然周**（周一 ~ 周日），不用滚动 7 天 |
| 2.3.2 | 统计是否可指定日期 | 日视图默认今天，支持点选任意日期回看；周/月视图按当前自然周/自然月 |
| 2.3.3 | 统计口径 | 见第六节表格，锁定"累计=全量、周期=筛选区间、日均=周期/已过天数" |
| 2.3.4 | 计时器后台策略 | 计时状态由全局 `TimerService` 持有，跨 Tab 保持；切后台用**心跳落盘**（每 10s 写一次开始时间戳），App 被杀重启后检测"未结束计时"弹恢复对话框；不做前台服务（阶段六可选增强） |
| 2.3.5 | 默认考试日期 | 首次启动填充 `当年 12 月 20 日`（考研初试一般在 12 月下旬），用户随时可改 |
| 2.3.6 | 跨零点记录归属 | 归计时**开始日**（2.1 模块2） |

#### 计时器状态机（新增）

```
IDLE ──开始──▶ RUNNING ──暂停──▶ PAUSED
 ▲              │                 │
 │              ▼                 ▼
 │            (RUNNING 结束)   (PAUSED 结束)
 └────── 保存弹窗 / 丢弃 ◀───────┘
心跳：RUNNING/PAUSED 状态下每 10s 把当前 start/累计暂停秒数写盘；
启动检测：存在未结束计时 → 弹窗【继续】/【丢弃】。
```

## 五、关键业务逻辑

### 1. 倒计时计算

读取 `exam_target_date`，与设备当前时间做日期差（按 0 点取整，避免时分秒误差）：
`剩余天数 = (目标日期0点 − 今天0点) / 86400000`，向下取整。修改日期后刷新。过期时切换过期文案。

### 2. 计时逻辑（增强）

- 开始：记录 `startTimestamp` 与累计暂停秒数，置心跳标记。
- 暂停/继续：累计暂停秒数，暂停期不计时。
- 结束：`elapsedSec = (now − start) − 累计暂停秒数`；`durationMin = ceil(elapsedSec/60)`。
- 保存：写入 study_record，清心跳标记；<60s 禁止保存。
- 恢复：启动时读到心跳标记 → 弹【继续/丢弃】。

### 3. 统计逻辑（口径见第六节）

根据选中的日/周/月区间生成 `[start, end]` 边界，单条 SQL 筛选：
`SELECT subject_name, SUM(duration_min) FROM study_record WHERE record_date BETWEEN ? AND ? GROUP BY subject_name`
再取全量 `COUNT(*)`、`SUM(duration_min)` 作为累计指标；周期内已过天数计算日均。

### 4. 备份/恢复逻辑

导出：读全表 + 配置 → 组装 JSON → 写文档目录 → share_plus 分享。
导入：选文件 → 解析校验 → 合并或覆盖写库 → 提示导入条数。

### 5. 数据流约定（新增）

页面数据由 `TimerService` / `StatisticsService` 通过 Riverpod `notifier` 暴露；编辑、删除、补录、导入成功后通知统计/首页刷新（监听数据库变更事件或手动 `invalidate`）。

## 六、统计口径定义表（新增，开发唯一依据）

| 指标 | 定义 |
|---|---|
| 周期（日） | 今天 0 点 ~ 明天 0 点（默认）；支持点选任意日期回看 |
| 周期（周） | 本周一 0 点 ~ 下周一 0 点（自然周） |
| 周期（月） | 本月 1 日 0 点 ~ 下月 1 日 0 点 |
| 当前周期总时长 | 周期区间内所有记录 `duration_min` 之和 |
| 累计专注次数 | 全量记录条数 `COUNT(*)`（不受筛选影响） |
| 总学习时长 | 全量 `SUM(duration_min)`（不受筛选影响） |
| 日均专注时长 | 周期总时长 ÷ 周期内已过天数（日视图即当日时长；周视图分母=周一至今的天数；月视图分母=1日至今的天数；空周期显示 0） |
| 各科耗时 | 周期内按 `subject_name` 分组求和 |
| 饼图占比 | 各科耗时 ÷ 当前周期总时长 × 100%（四舍五入到整数） |

## 八、边界场景与测试用例（新增）

| # | 场景 | 预期 |
|---|---|---|
| 1 | 计时不足 60 秒点结束 | 禁止保存，提示"学习时长太短" |
| 2 | 计时 1 分 30 秒 | 保存为 2 分钟（ceil） |
| 3 | 23:50 开始、00:20 结束 | 记录归属开始日（前一天），时长 30 分钟 |
| 4 | 计时中杀掉 App 重开 | 弹【继续/丢弃】对话框，恢复或清除心跳标记 |
| 5 | 修改考试日期为过去 | 首页显示"已考完 · 考试已结束 X 天" |
| 6 | 考试日期恰为今天 | 剩余 0 天，显示"已到考试日期" |
| 7 | 补录时长 > 1440 分钟 | 二次确认提示 |
| 8 | 某科目仅 1 条且为唯一记录，删除 | 饼图/统计归零，显示空态 |
| 9 | 编辑一条记录后切到统计页 | 数据实时刷新 |
| 10 | 导入损坏 / 版本不符的 JSON | 可读错误提示，不破坏现有数据 |
| 11 | 导入含重复 recordId | 合并模式跳过，覆盖模式清空重导 |
| 12 | 1000+ 条记录 | 日志列表分页 20 条/页，滚动流畅 |
| 13 | 跨时区 / 修改系统时间 | 倒计时按本地日期计算；夏令时地区按系统时间差 |
| 14 | 连续多段"其他"科目 | 饼图按科目合并，配色固定可区分 |
| 15 | 从未学习（0 记录） | 首页汇总显示 0；统计页/日志页空态占位 |
| 16 | 清空数据 | 二次确认输入"清空"后才执行，保留考试日期配置 |
